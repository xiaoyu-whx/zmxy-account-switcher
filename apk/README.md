# 造梦西游OL 换号器（安卓 App）

装进模拟器/手机里的 APK。**每个号手动登一次，之后点一下按钮就换号**，不用再输账号密码。

- 安装包：`换号器.apk`（20 KB）
- 包名：`com.zsw.switcher`
- 需要设备已 **root**（雷电9：设置 → 其他设置 → root权限 → 开启 → 重启模拟器）

## 原理

游戏登录成功后，会把"我已登录"写进自己目录（`shared_prefs` / `databases` / `app_webview` 里的 cookie 和 token）。
本 app 用 root 把这些文件打包成一份存档；换号时把存档写回游戏目录 + 重启游戏，游戏读到旧登录态就直接进。

## 第一次用（3 步）

1. 打开 app → 顶部「游戏包名」已经是 `org.yjmobile.zmxy`（造梦西游OL），不对就改掉并点「保存」
2. **手动登录一个号**（账号密码 / 4399 网页登录都行），进到选角色的界面
3. 回到 app：在「抓这个号」里填个名字（比如 `大号`）→ 点 **「抓取当前账号」**

日志出现 `完成：大号 大小 0.5 MB` 就成了。有几个号就重复 2-3 几次（每次记得先在游戏里登好那个号）。

> 第一次抓取时，模拟器会弹「已授予"换号器"超级用户权限」，允许即可。

## 以后换号（1 步）

在下面「账号」列表里，点那个号右边的 **「一键登录」**：

```
关游戏 → 清理旧登录态 → 写回存档 → 恢复权限 → 启动游戏
```

默认还会在游戏起来 **20 秒后自动回写**一次最新登录态（因为服务器每次登录可能刷新 token，不回写存档会慢慢过期）。
这里的秒数可在界面上改（游戏加载慢就调大）。

## 界面按钮

| 控件 | 作用 |
|---|---|
| 抓这个号 / 抓取当前账号 | 把**当前游戏里登着的号**抓成存档 |
| 一键登录 | 切到这个号 |
| 重抓 | 覆盖更新这个号的存档（存档过期、要重新登录时用） |
| × | 删除这个存档 |
| 刷新 | 重新读存档列表 |
| 诊断 | 打印 root 状态、包名、uid、数据目录、最近 20 分钟改动过的文件（排查用） |

## 存档在哪

```
/data/data/com.zsw.switcher/files/profiles/<名字>/snap.tgz   登录态存档
/data/data/com.zsw.switcher/files/profiles/<名字>/meta.txt   包名、目录清单、时间、大小
```

卸载 app 会一起删掉，记得别随便卸载。想看的话：`adb shell su -c ls /data/data/com.zsw.switcher/files/profiles/`

## 出问题看这里

| 现象 | 原因 / 处理 |
|---|---|
| `root: 拿不到 root！` | 模拟器没开 root，或没给本 app 授权（超级用户里允许一下） |
| 抓取失败「读不到 /data/data/...」 | 包名不对，或没有 root |
| 一键登录后游戏还是要登录 | 存档过期（服务器把 token 作废了）→ 手动登录这个号，点「重抓」 |
| 切换后黑屏/闪退 | 在 app 里点「诊断」看数据目录是否正常，必要时 `重抓` 一次 |
| 想换游戏 | 顶部改包名保存即可（任何 root 提取数据的安卓游戏都通用） |

## 重新编译

```powershell
# 需要：JDK 17 或 IntelliJ/Android Studio 自带的 jbr、Android SDK build-tools 34
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
# 产物：换号器.apk
```

源码：`src/com/zsw/switcher/MainActivity.java`，清单：`AndroidManifest.xml`。

> 注意：build-tools 34 自带的 d8(R8 8.2) 处理不了 javac 21 生成的 class（会内部 NPE），
> 所以 build.ps1 会优先用 **JDK 17 / JBR** 编译。

## 风险提示

- 这是登录凭证复用：同一个号在两处同时用会互相顶号；4399 风控也可能判定异常登录。
- 存档等于账号钥匙，别发给别人。
- 先用小号试，别拿主要账号第一个试。
