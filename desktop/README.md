# 造梦西游OL 换号器

一个双击就能用的小窗口，把「输账号密码登录」变成「点一下按钮」。

## 它是怎么做到的

不用密码，用的是**登录态数据**。游戏登录成功后，会把"我已经登录了"这件事写进自己安装目录的
几个文件里（`shared_prefs` / `databases` / `app_webview` 里的 cookie 和 token）。
这个工具做两件事：

1. **抓取**：把当前登录状态的这几个文件打包成一个存档（每个号一份）
2. **写回**：换号时把对应存档写回游戏目录，然后重启游戏 → 游戏读到旧登录态，直接进去

所以每个号只需要**手动登录一次**，之后就是点按钮的事。

## 用之前必须做的两件事

1. **模拟器开 root**
   雷电9 → 右上角设置 → 其他设置 → root权限 → 开启 → 重启模拟器。
   （没 root 就读不到游戏的数据目录，工具会提示你。）
2. **游戏装好、能正常登录**
   第一次每个号都要自己手动登一次，把登录态采集下来。

## 第一次使用（5 步）

1. 打开雷电9，启动造梦西游OL
2. 双击 `启动换号器.bat`
3. 点「刷新」→ 设备框里选中模拟器（右边显示 `root 正常` 才对）
4. 点「检测应用」→ 选游戏包名。
   猜不出来就点「诊断」：它会列出最近 20 分钟有数据改动的应用，你刚登录过的那个就是游戏
5. 在游戏里**手动登录一个号** → 窗口里填名字（比如 `大号`）→ 点「抓取当前账号」

看到 `已保存存档：大号  大小 xx MB` 就成了。有几个号就重复第 5 步几次。

## 以后换号（1 步）

点那个号右边的 **「一键登录」**：

```
关闭游戏 → 上传存档 → 覆盖登录态 → 重启游戏 → 自动登录
```

默认还会在游戏进去之后自动把最新登录态**写回**存档（因为每次登录服务器可能会刷新 token，
不回写的话存档会慢慢过期）。等待秒数默认 20 秒，游戏加载慢就调大。

## 界面上其他按钮

| 按钮 | 干什么 |
|---|---|
| 更新数据 | 手动把这个号重新抓一遍（存档过期、登录失效时用） |
| 诊断 | 输出包名、uid、数据目录、以及最近 20 分钟改动的文件，排查问题用 |
| 打开存档文件夹 | 看看 `profiles\` 里存了什么 |
| 登录后自动回写 | 关掉的话，存档只在抓取时更新 |

## 常见问题

**「抓取失败：没找到数据目录」**
包名选错了，或者模拟器没开 root。点「诊断」看真实情况。

**「切换失败 / 存档不存在」**
存档目录 `profiles\名字\` 里必须有 `snap.tgz`。没有就重新抓一次。

**点了一键登录，游戏起来了但还是要登录**
说明存档过期了（服务器把 token 作废了）。重新手动登录这个号，点「更新数据」。
勾上「登录后自动回写」能明显减少这种情况。

**多开（三个窗口 A/B/C）**
设备下拉框里会列出多个 `127.0.0.1:5555 / :5557 / :5559`。
切到哪个窗口就选哪个设备，账号存档是通用的。

**改名 / 删除**
直接在 `profiles\` 文件夹里改文件夹名或删掉即可，工具重启后按文件夹读列表。

## 注意

- 这是**登录凭证复用**，同一串数据在两处同时用会互相顶号；平台风控也可能判定异常登录。
  小号先试，别拿主要账号的第一个试。
- 存档里等于是你账号的钥匙，别发给别人。
- `config.json` 记着 adb 路径、设备、包名，删掉会自动重建。
- 出错时看 `logs\日期.log`。
- 双击 bat 会顺带开一个**最小化**的命令行窗口，别关它，那是程序本体；关掉等于退出。

## 命令行用法（不想开窗口时）

```powershell
# 自检：看 adb 路径、设备、root 状态
powershell -NoProfile -ExecutionPolicy Bypass -File 换号器.ps1 -SelfTest

# 列出设备和已安装应用
powershell -NoProfile -ExecutionPolicy Bypass -File 换号器.ps1 -Cli list

# 诊断（不填 -Pkg 就会自己找"刚登录过的那个应用"）
powershell -NoProfile -ExecutionPolicy Bypass -File 换号器.ps1 -Cli diag

# 抓取当前登录的号
powershell -NoProfile -ExecutionPolicy Bypass -File 换号器.ps1 -Cli capture -Name 大号 -Pkg 游戏包名

# 一键登录
powershell -NoProfile -ExecutionPolicy Bypass -File 换号器.ps1 -Cli login -Name 大号
```

可以让按键精灵用 `RunApp` / 命令行调用最后一条，把换号并入你现有的挂机流程。

## 文件说明

```
换号器.ps1        主程序（PowerShell 脚本，无依赖）
启动换号器.bat     双击启动
config.json       adb 路径 / 设备 / 包名（自动生成）
profiles\大号\     snap.tgz（登录态存档） + meta.json（记录包名、时间、设备）
logs\日期.log      运行日志
```
